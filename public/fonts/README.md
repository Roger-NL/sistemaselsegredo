Local typefaces for the BasedSpeak comic theme.

- Bangers Regular: [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/bangers). License: `OFL-Bangers.txt`.
- Barlow Regular and SemiBold: [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/barlow). License: `OFL-Barlow.txt`.

The original font files and licenses are bundled locally. The browser does not contact Google Fonts to load them. Display lettering is reserved for headings; English learning content retains its original case and punctuation in the body typeface.
